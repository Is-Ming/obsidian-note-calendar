## 介绍

一个 Obsidian 日历插件，支持公历、农历、节日、调休、节气的显示，自动将笔记创建/修改日期关联到日历，并支持一键创建日记、周记、月记、季记和年记。

## 功能特性

1. **日历视图**：月视图，淡紫色调，显示周数、公历、农历、节日、节气、调休班休标记。

2. **笔记关联**：自动扫描仓库笔记，按创建/修改日期标记到日历上（绿色=新增，蓝色=更新）。

3. **笔记创建**：支持日记、周记、月度笔记、季度笔记、年度笔记五种类型，标题格式和保存路径各自独立配置，弹窗文件夹路径支持筛选选择。

4. **季度自定义**：日历标题可显示当前季度，支持数字（1季度）、季节（春季）或自定义命名，首季起始月可调。

5. **颜色管理**：主题色和周末色支持自定义，一键重置为默认。

6. **模板支持（可选）**：集成 Templater 插件，创建五类笔记时自动套用模板；未安装 Templater 不影响任何现有功能。

## 插件设置说明

### 外观
- **主题模式**：跟随Obsidian / 深色 / 浅色
- **一周起始日**：周日或周一
- **周末颜色 / 主题颜色**：可自定义，点击旁 ⟳ 按钮还原默认
- **字体 / 字号**：11种字体，字号 10-20px

### 显示
- 公历假日、调休、农历日期、农历假日、节气 — 各独立开关

### 季度显示设置
- **季度显示模式**：数字（1季度）/ 春夏秋冬（春季）/ 自定义命名
- **首季起始月份**：季节/自定义模式下设置第一个季度从哪月开始
- **自定义季度名称**：逗号分隔4个名称，不足自动补齐

### 五类笔记设置（日记 / 周记 / 月度 / 季度 / 年度）
- 每类独立配置**标题格式**（支持 YYYY / MM / DD / {week} / {quarter} 等变量）
- 每类独立配置**默认文件夹路径**，路径项旁 📁 按钮可弹出文件夹选择窗口自动填充
- 每类独立配置**模板文件**（需 Templater 插件，见下方"模板支持"），路径项旁按钮可弹出文件选择窗口，路径填写错误时输入框显示红色边框

### 笔记扫描
- **扫描目录**：限定只扫描某目录下的笔记（留空=全库），与创建笔记的保存路径无关，支持 📁 按钮选择
- **手动扫描**：点击立即重新扫描

## 使用方法

### 基础操作
- 点击 `‹‹` `‹` `›` `››` 切换月/年
- 点击「今」回到今天
- 点击任意日期查看当天笔记列表

### 创建笔记
列表顶部按钮 `[+ 周 月 季 年]`，分别创建对应类型笔记，弹窗中可修改标题和保存路径，文件夹路径支持输入筛选和 📁 树状选择。

### 笔记管理
- 新建、修改、重命名、删除笔记时自动刷新
- 点击笔记名称直接打开对应文件

### 模板支持（Templater，可选）

本插件可选集成 Templater 插件：创建日记/周记/月记/季记/年记时自动套用模板。**不安装 Templater 不影响本插件任何现有功能。**

**前提**：安装并启用社区插件 [Templater](https://github.com/SilentVoid13/Templater)。

**配置步骤**：

1. 用 Templater 语法写一个模板文件（普通 .md 文件即可，不要求放在 Templater 的模板目录内），例如 `templates/日记模板.md`：

   ```markdown
   ---
   created: <% tp.date.now("YYYY-MM-DD HH:mm") %>
   type: daily
   ---

   # <% tp.file.title %>
   ```

2. 打开本插件设置 → 日记设置 → **模板文件**，填入该文件路径（或点击旁边的按钮在文件选择窗口中选择）
3. 点击日历笔记列表的 `+` 创建笔记，内容即为模板渲染结果

**行为说明**：
- 模板路径留空 = 创建空笔记（默认行为，与未安装 Templater 时一致）
- `<% tp.file.title %>` 会替换为弹窗中最终确定的标题
- 模板文件不存在或渲染失败：保留空笔记并弹出提示，不会中断创建流程
- 若你在 Templater 中开启了"文件夹模板"（Folder Templates）并指向笔记的保存目录，本插件会自动跳过自己的模板套用，避免内容重复（建议只在一处配置）

## 安装指南

### 方式一：手动安装
1. **下载插件**：从[发布页面](https://github.com/Is-Ming/obsidian-note-calendar/releases)下载最新版本的插件压缩包note-calendar.zip。

2. **安装插件**：将插件压缩包note-calendar.zip解压,解压后的文件夹名称为note-calendar,将其放入Obsidian的插件目录中。

3. **启用插件**：在Obsidian中打开设置，找到插件列表，启用"Note Calendar"插件。

### 方式二：使用Obsidian社区插件市场安装

1. **打开Obsidian社区插件市场**：在Obsidian中打开设置，找到社区插件市场。

2. **搜索插件**：在插件市场中搜索"Note Calendar"插件。

3. **安装插件**：点击插件列表中的"安装"按钮，确认安装。

4. **启用插件**：在Obsidian中打开设置，找到插件列表，启用"Note Calendar"插件。
